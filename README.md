# Penny Reset — sales page

Static landing page for the 2027 Money Reset Planner, served by GitHub Pages.

- `index.html` — sales page. Set the lava.top checkout link in `CHECKOUT_URL` at the bottom.
- `privacy.html`, `terms.html` — legal pages. Replace `CONTACT_EMAIL`.
- `assets/` — page previews only. Product files are NOT stored here (the repo is public).
